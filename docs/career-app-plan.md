# 心動くキャリア対話サービス（開発構想メモ）

## 1. コンセプト

「考えてから話す」のではなく「浮かんだことをそのまま話す」ことで、
自分でも気づいていなかった"心動くキャリア"を、AIキャラクターとの対話を通じて言語化するサービス。

対話の最後には、AIが内容を体系的にまとめ、
**トラベルノートブック風のデザイン**でギフトとして渡す。

---

## 2. 全体の画面フロー（MVP）

```
[Step 0] キャラクター選択画面
    ↓ ユーザーが3人から1人選ぶ
[Step 1] キャラクターが登場（画面中央）
    → 「こんにちは、簡単に自己紹介をお願いします」で対話開始
    ↓
[Step 2] Q1〜Q10 の対話（1問1答形式）
    → キャラクターが音声(TTS)で問いかける
    → ユーザーが音声で回答（Recorderで文字起こし）
    → 回答をstateに貯めていく
    ↓
[Step 3] AIによる要約＆確認（Q7の後）
    → 「ここまでの話をまとめてみるね」→ 要約を提示
    → 「しっくりくる？」→ Yes: Step4へ / No: 違和感を深掘り(Q9)してから再要約
    ↓
[Step 4] 最終言語化
    → 心動くキャリア／やりたい仕事／
       今できるアクション／助けが必要なアクション／学ぶといいこと
    ↓
[Step 5] トラベルノートブック風ギフト画面
    → 日付・所要時間つきで表示
    → （将来）マイページに保存
```

---

## 3. キャラクター設計（MVP）

3種類のキャラクターを用意し、それぞれ「口調」と「聞き方の温度感」だけ変える
（プロンプトのシステムメッセージを変えるだけで実現可能。既存の`tone`選択の仕組みを流用できる）。

| キャラ例 | 口調イメージ | 向いている人 |
|---|---|---|
| 🌱 やさしい先輩 | 共感重視、ゆっくり | じっくり話したい人 |
| 🔥 情熱コーチ | テンポよく背中を押す | パッと勢いで話したい人 |
| 🧭 冷静なナビゲーター | 論理的に整理してくれる | 頭を整理しながら話したい人 |

→ 技術的には「キャラクターごとのsystem prompt定義」を1つのオブジェクトにまとめておくだけでOK。

---

## 4. 対話の10ステップ（プロンプト設計のたたき台）

| # | 質問の主旨 | 備考 |
|---|---|---|
| 0 | 自己紹介をお願いします | 導入・アイスブレイク |
| 1 | 力が湧く/心動くことは？ | オープンクエスチョン |
| 2 | 具体的なエピソードと、心動いた瞬間 | 深掘り |
| 3 | 他にも心動くことがあれば（最大5つ） | ループ質問（配列に貯める） |
| 4 | そこで培われた強みは？ | 抽象化 |
| 5 | その強みを活かせる仕事は？（業界職種問わず） | 発散 |
| 6 | どんな人の力になれると嬉しい？ | 価値観 |
| 7 | 10年後こうなっていたら理想？ | ビジョン |
| — | AIが中間要約を提示 | 「しっくりくる？」の分岐 |
| 8 | しっくりきた？（Yes/No分岐） | 分岐ポイント |
| 9 | （Noの場合）どこが違和感？本音は？ | 深掘り、その後7の要約に戻る |
| 10 | 実現のために、今できること／できないことは？ | クロージング |

→ 最終的にAIへ「これまでの全回答」を渡し、以下4点を出力させる：
1. 心動くキャリア（要約）
2. やってみたい仕事
3. 今できるアクション／助けが必要なアクション（分けて）
4. これから学ぶといいこと

## 5. 技術構成（既存資産の再利用）

すでにこのプロジェクトにある部品がそのまま使えます。

| 既存の部品 | 新企画での使い道 |
|---|---|
| `Recorder.tsx` | ユーザーの音声回答→文字起こし（そのまま流用） |
| `api/tts/route.ts` (edge-tts) | キャラクターの問いかけを音声で読み上げ |
| `api/coach/route.ts`の設計パターン | 新しく `api/career/route.ts` を作り、対話ステップに応じたprompt分岐を実装 |
| `FaceMeter.tsx`（丸窓カメラ） | 今回は必須ではないが、任意で「対話中の表情」を記録し、後で本人にフィードバックする拡張も可能 |

## 6. データの持ち方（フロント側 state 設計案）

```ts
type CharacterId = "gentle" | "passionate" | "navigator";

type Step =
  | "select-character"
  | "intro"
  | "q1" | "q2" | "q3-loop" | "q4" | "q5" | "q6" | "q7"
  | "summary-check"
  | "q9-if-no"
  | "q10"
  | "final-gift";

type Answers = {
  intro: string;
  energizing: string;
  episode: string;
  moreEnergizing: string[]; // 最大5つ
  strength: string;
  wantedJob: string;
  whoToHelp: string;
  visionIn10Years: string;
  summaryFeedback: "yes" | "no" | null;
  honestFeeling: string; // q9
  canDo: string;
  needHelp: string;
};
```

## 7. 「トラベルノートブック」ギフト画面のイメージ

- 見た目：紙のノートブック風デザイン（globals.cssに新しいテーマを追加）
- 上部に「日付」「対話にかかった所要時間」
- 中身：
  - 「あなたの心動くキャリア」
  - 「やってみたい仕事」
  - 「今できるアクション」「助けが必要なアクション」
  - 「これから学ぶといいこと」
- 印刷やスクショしたくなるような、余白のある優しいデザインが良さそう

## 8. MVPで最初に作る範囲（提案）

いきなり全部作ると大変なので、以下の順番がおすすめです。

1. キャラクター選択画面（3枚のカードを並べるだけ）
2. 対話フロー（テキスト入力でOK、音声は後回し）＋ state管理
3. `api/career/route.ts` で最終要約のAI生成
4. ギフト画面（ノートブックデザイン）
5. （後回し）Recorderによる音声入力を対話に組み込む
6. （後回し）TTSでキャラクターの声を出す
7. （さらに後回し）マイページ・保存機能
